# 🧠 PredictBase Smart Contract

This is the official smart contract for [PredictBase](https://predictbase.app) — a decentralized prediction market platform built on **Base Mainnet**, enabling USDC-based bets on real-world events.

---

## 🚀 Key Features


- Bet with **USDC**
- Anyone can **create markets** and earn **1% of the volume**
- Transparent and secure **market resolution**
- ✅ **Verified contract on Base Mainnet**
